# X2609-492 UniMICE Frontend

Фронтенд-оболочка для Цифровой платформы корпоративных мероприятий UniMICE —
server-rendered админ-панель для работы с заявками на мероприятия.
Проект выполняется в рамках проектного практикума (код X2609-492).

Админка — «тонкий клиент» над REST API существующего бэкенда платформы:
вся бизнес-логика и данные остаются на стороне бэкенда, здесь только
отображение и формы. Весь интерфейс рендерится на сервере — ручного
HTML/JavaScript нет, фреймворк админ-панели закрывает всю фронтовую часть.

## Стек

- PHP 8.3+
- [Laravel](https://laravel.com/)
- [MoonShine 4](https://getmoonshine.app/) — фреймворк админ-панелей на Laravel:
  ресурсы, CRUD-страницы, фильтры, формы и меню описываются на PHP

## Архитектура

```
app/
├── MoonShine/            # ресурсы и страницы админ-панели
└── Services/UniMice/     # клиентский слой к REST API платформы (HTTP-клиент, DTO)
```

Принципы:

- бэкенд платформы вызывается только по REST API, своей базы бизнес-данных
  у приложения нет;
- конфигурация подключения (base URL, учётные данные сервиса) — только
  через переменные окружения, секреты в репозитории не хранятся;
- поведение интерфейса зависит от роли текущего пользователя
  (данные роли приходят из API).

## Разработка

Требования: PHP 8.3+, Composer.

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Переменные окружения для подключения к API задаются в `.env`
(см. `.env.example`): base URL и учётные данные сервисной учётной записи.

## Веточная модель

Ветка `main` защищена: изменения попадают только через pull request
из feature-веток (`feature/*`, `docs/*`, `fix/*`).
